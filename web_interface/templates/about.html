PROJECT LUNA: CYBERNETIC COGNITION

Project LUNA (Logical Utility & Neural Arm) represents a revolutionary advancement in human-robot interfaces, designed as a highly integrated cybernetic arm and hand system. It synthesizes the computational efficiency of locally-hosted vision pipelines with the massive cognitive flexibility of advanced large language models. Operating on a robust dual-serial hardware backplane, LUNA bridges the physical gap between digital twins and actual robotic manipulators.

Developed by Team Invicta at Universal AI University, Karjat, LUNA serves as an industrial-grade research platform exploring bimanual coordination, safety perimeters, autonomous spline-based path planning, and voice-command reasoning models.

🎯 SYSTEM MISSION OBJECTIVES

  • Bimanual Control: Dynamic, low-latency target synchronization across separate left and right arm pipelines.
  • Cognitive Reasoning: Continuous semantic analysis of complex operator natural language requests via Gemini 1.5 Pro.
  • Anti-Gravity Safety: Zero-tolerance hardware perimeter watchdog enforcing microsecond halt triggers upon intruder proximity detection.

🎛️ DISTRIBUTED COMPUTE INFRASTRUCTURE

  • RTX 4060 GPU Orchestrator: Driving 100+ FPS vision processing running YOLOv8 object recognition and MediaPipe hand skeleton tracking.
  • Dual-PCA9685 Co-Processors: High-precision 16-channel hardware PWM generation operating over distinct I2C nodes (0x40 and 0x41).
  • Arduino & ESP32 Hubs: Real-time hardware telemetry aggregation and laser Time-of-Flight sensor read-outs.

🔬 ADVANCED ROBOTIC ENGINE DESIGN

📐 Kinematic Splines

LUNA utilizes custom analytical Inverse Kinematics equations mapped to three-dimensional vector targets. Instead of disjoint angular jumps, target coordinates are computed as smooth cubic Hermite splines. This ensures optimal energy distribution across MG996R high-torque actuators, yielding fluid organic movement.

🛰️ Autonomous A* / RRT Planner

The platform contains a dedicated 3D Path Planning engine. Bounded by exact kinematic workspace ranges, the search space is discretized into a 3D occupancy voxel grid. Operator-defined collision perimeters are calculated, allowing A* algorithms (optimality) and Rapidly-Exploring Random Trees (RRT) to map collision-free paths.

💾 Supabase & Local DB Fallback

All operational mission logs, emergency alerts, calibration curves, and user authentication events are committed asynchronously via an independent logger thread to Supabase PostgreSQL, keeping the main server completely unblocked. An offline SQLite fallback triggers automatically to ensure zero loss of telemetry.
