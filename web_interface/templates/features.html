🛠️ Hardware Engineering Specification

LUNA's physical chassis is an optimized 4-Degree-of-Freedom (DOF) anthropomorphic manipulator, engineered to match human hand kinematics. Actuation is handled by low-latency MG996R and DS3218 high-torque metal-geared servos configured across split PCA9685 I2C expansion boards. To prevent current draw spikes from causing microcontroller brown-outs, a dedicated 5V 10A buck-regulated external power bus supplies the motors directly, while opto-couplers isolate the high-frequency control lines.

🧠 The Neural Brain: Google Gemini 1.5 Pro & Local Voice Uplink

LUNA's semantic comprehension is driven by the Google Gemini API. This allows operators to issue highly abstract voice commands (e.g., "LUNA, carefully raise the arm and point toward the highest object in view") which are captured via a persistent Whisper microphone queue, parsed into actionable angular vectors, and executed. Furthermore, you can hot-reload LUNA's system directive prompts dynamically inside the dashboard to modify the robot's voice, safety thresholds, or task priorities instantly.

CORE INDUSTRIAL-GRADE CAPABILITIES

👁️ Spatial Vision Processor

A multi-threaded Python vision pipeline processes camera frames in parallel, mapping YOLOv8 spatial bounding boxes for 100+ objects while concurrently running MediaPipe hands to mirror finger flexion in real-time.

🛸 Weightless Teleoperation

Integrated Xbox / PlayStation gamepad loop running at 30Hz with dual joysticks mapping to delta-time angle velocities, allowing fluid control over arm elevation, wrist roll, and finger grip curling.

🛡️ Safe-Zone Laser Perimeter

An ESP32-governed array of VL53L0X Time-of-Flight laser rangefinders monitors the physical zone around LUNA. If any object enters within 15cm, the backend halts all commands instantly to ensure operator safety.

🦾 Coordinated Bimanual Operations

Features simultaneous dual-serial connections allowing left and right arm target control over separate COM ports. Interpolation engines run on both threads to ensure synchronous, jitter-free joint movements.

🌐 Digital Twin 3D Splines

WebGL and Three.js-powered digital twin loads your custom LUNA 3D mesh model, matching physical motor degrees in real-time, complete with dynamic spline path tracers projecting spatial routes.

📋 Secure User Audit Trails

Comprehensive security audit trails track operator actions and login histories, preserving critical telemetry and command actions with absolute timestamps inside secure PostgreSQL databases.
